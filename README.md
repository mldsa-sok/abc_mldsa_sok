# ABC for Fault Attacks on ML-DSA

Interactive companion website of the anonymous submission *SoK: Fault Injection Attacks on ML-DSA*.

## Views

- **Fault map**: ML-DSA as specified in FIPS 204, with every published fault attack placed at the line it targets, together with the targeted countermeasures.
- **Attack matrix**: the assumptions, fault class, key recovery and countermeasure verdicts of each attack. Filter by requiring or ruling out assumptions.
- **Hardware experiments**: injection technique, device and implementation of each attack.
- **Open-source implementations** and **Patents**: the libraries targeted by the attacks and the patented countermeasures.

All data is taken from the tables of the paper and the cited public works.
